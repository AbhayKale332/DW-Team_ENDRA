Idea Title:
DepthWizard: One Image. Measurable Heights. A Landscape You Can Explore.

Idea Description:
A satellite image can show where a road, building or river lies, but it cannot directly tell us how high the surrounding land is. That missing dimension matters when teams need to understand a floodplain, examine a hillside or assess access around dense buildings. Detailed elevation surveys require equipment, suitable satellite acquisitions, time and money. Existing elevation maps can provide regional context while missing smaller structures.

DepthWizard turns a single RGB satellite or aerial image into an estimated surface map and an interactive 3D landscape. Users upload an image, generate heights, and explore the result from above or through a first-person flythrough. They can inspect height differences, examine slopes and elevation profiles, compare predictions with reference data, and export the output for further mapping work.

The solution adapts to the information available. An ordinary PNG or JPG produces a relative surface model that shows which features are higher or lower. A GeoTIFF with geographic coordinates can be aligned with an open elevation source, such as SRTM or Copernicus, to produce elevations in metres against a known height reference. Surveyed control points provide another way to calibrate the result. The interface clearly identifies the type of height being displayed.

Our approach combines broad elevation context with finer detail learned from overhead imagery. The model learns the shapes of buildings, trees and open ground from paired images and height data. Reference elevation data anchors the overall surface. Since coarse elevation maps may already include part of the height of buildings and trees, the calibration accounts for that contribution instead of simply adding the two layers and counting structures twice.

The same workspace connects prediction, inspection and validation. Users can move from a suspicious feature in the 3D view to its height profile or reference comparison. Where model uncertainty is available, an overlay helps identify areas that deserve closer checking. This makes the output useful for review as well as presentation.

The project is feasible because it builds on an existing trained model, open reference data, a working 3D interface and desktop packaging. Large images are processed in overlapping sections to manage memory and reduce visible seams. With the model and required reference data installed locally, the desktop application supports offline processing and exploration.

DepthWizard is intended to help disaster management teams, planners and mapping analysts obtain an initial understanding of an area when detailed surveys are unavailable. Its value is a practical route from one image to an inspectable 3D surface, with clear height references and tools to check the estimates before using them in further analysis.

Abstract/Summary:
Elevation is essential to understanding a landscape. It influences where water collects, how steep an approach is and how buildings sit relative to nearby terrain. Yet a satellite image, often the first information available about an area, presents that landscape as a flat picture. Producing a detailed elevation survey usually requires additional images, specialised sensors or field measurements. During early disaster assessment and planning, these inputs may be unavailable or take time to obtain.

DepthWizard addresses ISRO Problem Statement 26175 by converting a single optical RGB image into an estimated Digital Surface Model, or DSM, and a navigable 3D scene. A DSM describes the visible surface, including terrain, buildings and vegetation. The aim is to make estimated elevation accessible through a workflow that supports both numerical inspection and visual understanding.

The user begins by uploading a PNG, JPG or GeoTIFF. The application checks the image and its geographic information, then applies a model adapted to overhead imagery. This adaptation matters because models trained on everyday photographs see streets and buildings from very different viewpoints. Training with paired aerial images and height maps helps the model learn the patterns present in a top-down view. GAMUS and other openly available remote-sensing datasets provide a practical basis for this work.

The processing path depends on the input. For an image without geographic coordinates, DepthWizard produces a relative surface model. This lets the user explore the arrangement and relative heights of visible features without presenting them as verified absolute elevations. For a georeferenced image, the system aligns the prediction with an available reference elevation map or suitable surveyed control points. The resulting absolute DSM retains its geographic position and identifies the height reference used.

A central part of the approach is how image-based detail and reference elevation are combined. A coarse elevation map captures the broad shape of an area, while the model estimates smaller features visible in the image. These sources cannot always be added directly: reference maps may already contain some contribution from rooftops and tree cover. DepthWizard accounts for this overlap when anchoring the surface, helping avoid inflated elevations while retaining the finer structure estimated from the image. Agreement with the anchoring map is treated as a calibration check; independent reference data is needed to establish prediction accuracy.

The original image is then placed over the generated surface to create a textured 3D scene. Users can orbit the landscape, inspect it from a map view, or fly through it at different heights. Measurement tools provide point heights, height differences, slopes and cross-sectional profiles where the image scale and height reference support them. This allows an analyst to examine how a feature relates to its surroundings rather than interpreting a height map in isolation.

Validation is part of the same workflow. Users can load a reference surface, inspect an error map and compare estimated heights with known values. Model uncertainty, when available, provides an additional indication of where predictions may be ambiguous. The application keeps relative height, height above local ground and absolute surface elevation distinguishable, since confusing these quantities can make a plausible-looking scene misleading.

Development has already produced trained model versions, an interactive viewer, measurement and reference-comparison tools, standard exports and a desktop deployment path. A documented evaluation of the current model used 2,088 validation tiles across four datasets. This provides preliminary evidence of feasibility, while performance on unseen ISRO imagery and the complete absolute-elevation workflow still requires separate assessment. The evaluation plan covers urban, sparse, hilly and forested landscapes, with errors reported by landscape as well as overall. Height accuracy will be assessed using RMSE, MAE and correlation against suitable independent references.

The intended input range is 0.35 m to 10 m spatial resolution, including the 0.6 m Cartosat-2S imagery specified for final evaluation. Resolution changes and differences between sensors must be included in development and validation. At coarser resolutions, small structures may no longer be visible, so the level of recoverable detail will vary. The approach does not depend on acquisition time or sun-angle metadata, which may be absent from the supplied images.

Practical deployment is supported by processing large images in overlapping sections and reusing established tools for geographic data and 3D rendering. The desktop version can run locally with an installed model and locally available reference data. Outputs include georeferenced height rasters where applicable and reusable 3D models. Source code and technical documentation will accompany the integrated solution.

For disaster management, DepthWizard can help teams inspect terrain context, recognise areas that need closer examination and communicate site conditions through a shared 3D view. For planning and mapping, it offers a way to assess visible structures and surface changes when detailed elevation data is limited. Its distinctive contribution is the combination of image-based height estimation, reference-aware calibration and direct visual validation in one application. The intended outcome is a surface that users can explore, measure and question, with enough context to decide where further survey work is needed.
