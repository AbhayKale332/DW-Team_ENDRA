Bring height estimation and 3D terrain to your desktop. Choose your operating system and whether to include the model. Releases and download sizes are fetched directly from GitHub.

<Downloads />

## Start with an image

Install the application, open a PNG, JPG or GeoTIFF, then select **Estimate heights**. A model-included download selects local inference automatically. A model-free download selects hosted Hugging Face inference and needs an internet connection.

You can add your own compatible DepthWizard V5 ONNX model later through **Model → Install ONNX model…**. Keep its `.onnx.json` metadata and any external weight files alongside the graph. Importing it selects local inference automatically.

## Before downloading

### Windows

Unsigned installers may show a Windows security prompt. Download the `.exe` from the official release and verify it against <ChecksumLink>SHA256SUMS.txt</ChecksumLink> when needed.

### macOS

Choose **Apple Silicon** for an M-series Mac, or **Intel** for an Intel Mac. macOS may show a security prompt for the unsigned app; download the `.dmg` from the official release and verify it against <ChecksumLink>SHA256SUMS.txt</ChecksumLink> when needed.

### Linux

Mark the AppImage executable before opening it. Download it from the official release and verify it against <ChecksumLink>SHA256SUMS.txt</ChecksumLink> when needed.

### Model and connectivity

Model-included downloads are larger and use your CPU for predictions. Basemaps, remote elevation data and live OSM still need internet access.
