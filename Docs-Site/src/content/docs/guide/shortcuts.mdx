---
title: Keyboard shortcuts
description: Every keyboard shortcut in the DepthWizard web app.
---

Press <kbd>?</kbd> in the app to show this list. Shortcuts are ignored while you are typing in a text field.

## File

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | Open image, project or result bundle |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Save project |
| <kbd>Ctrl</kbd> + <kbd>E</kbd> | Export GeoTIFF |
| <kbd>Alt</kbd> + <kbd>N</kbd> | New project |

## View

| Keys | Action |
|---|---|
| <kbd>1</kbd> | 3D DSM view |
| <kbd>2</kbd> | Height map |
| <kbd>3</kbd> | Input image |
| <kbd>[</kbd> | Toggle project panel |
| <kbd>]</kbd> | Toggle inspector |

## Navigation

| Keys | Action |
|---|---|
| <kbd>R</kbd> | Reset camera (Orbit mode) |
| <kbd>N</kbd> | Face north |
| <kbd>+</kbd> / <kbd>−</kbd> | Zoom in / out |
| Arrow keys | Orbit (canvas focused) |
| <kbd>F</kbd> | First-person walk (toggle) |
| <kbd>G</kbd> | Flight simulator (toggle) |
| <kbd>T</kbd> | Drone tour (toggle) |
| <kbd>Esc</kbd> | Leave walk / flight / tour |

In walk mode: <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> move, <kbd>Shift</kbd> runs, <kbd>Space</kbd> / <kbd>C</kbd> go up / down. In flight mode: <kbd>W</kbd> / <kbd>S</kbd> throttle, arrow keys pitch and roll, <kbd>Q</kbd> / <kbd>E</kbd> yaw, <kbd>Shift</kbd> boosts, <kbd>R</kbd> levels out.

## Tools & help

| Keys | Action |
|---|---|
| <kbd>O</kbd> | All 3D objects off / back to your selection |
| <kbd>?</kbd> | Keyboard shortcuts |

On macOS, use <kbd>⌘</kbd> in place of <kbd>Ctrl</kbd>.
